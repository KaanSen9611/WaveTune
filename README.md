# WaveTune

**Your music. Your vibe. Your questionable playlist choices.**

WaveTune is a lightweight desktop MP3 player that lets you enjoy your local music without judging your taste. Just press play and pretend you have a DJ career.

## Features

- Play local audio files
- Clean and modern interface
- Playlist management
- Playback controls: play, pause, skip, and seek
- Volume control
- Shuffle and repeat modes
- Album artwork and track information

## Tech Stack

- HTML
- CSS
- JavaScript
- Electron
